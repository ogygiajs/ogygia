# @ogygia/testing

## 0.14.0

### Minor Changes

- [#603](https://github.com/ogygiajs/ogygia/pull/603) [`cb841aa`](https://github.com/ogygiajs/ogygia/commit/cb841aad9c03a3e4080a54efe8c224f2aeecbd9a) Thanks [@PuruVJ](https://github.com/PuruVJ)! - `OgygiaDriver` gains an optional `addInitScript(source)`: `new Ogygia(driver)` hands it the testing engine as it is made, so a custom driver (Puppeteer's `evaluateOnNewDocument`, for one) gets the engine in every page it loads after that. `playwrightDriver` and `withOgygia` use it.

- [#531](https://github.com/ogygiajs/ogygia/pull/531) [`dc985cf`](https://github.com/ogygiajs/ogygia/commit/dc985cf55ccb6cadf84a406415357b229819ba11) Thanks [@PuruVJ](https://github.com/PuruVJ)! - - `@ogygia/testing`: `withOgygia` injects its own copy of the testing engine into each page before it loads (one bundled script, Playwright's `addInitScript`), so the engine always matches the package's version. `page().self.bytes` is 0 then (the page downloads none of it), and `page().self.phases.engine` is the engine's own start.
  - `@ogygia/devtools`: the dock's realm lends the injected engine what only the app's build knows (dev or not, the regions' names, the props lookup), and the leftovers watch keeps one record per page that any copy of the readers can read.

- [#605](https://github.com/ogygiajs/ogygia/pull/605) [`ec75d61`](https://github.com/ogygiajs/ogygia/commit/ec75d619bd9178d4631e314631254d44e3dd4121) Thanks [@PuruVJ](https://github.com/PuruVJ)! - - `@ogygia/testing`: `testing()` from `@ogygia/testing/vite`, listed beside `ogygia()`, feeds the testing engine a test injects, so `page()`, `hydration()`, `record()` and `settled()` work without devtools in the app. A visitor runs nothing of it. `profile()` still needs `devtools({ profiler })`.
  - `@ogygia/testing`: the injected engine starts the page beacon itself, so a page without the devtools server is measured too.
  - `@ogygia/devtools`: with both the dock and `testing()` in an app, each runtime hook call is recorded and measured once.

### Patch Changes

- [#475](https://github.com/ogygiajs/ogygia/pull/475) [`81a40ea`](https://github.com/ogygiajs/ogygia/commit/81a40ea61ad4345543ddbe5d270b734a531c0122) Thanks [@PuruVJ](https://github.com/PuruVJ)! - Durations are measured on the monotonic clock: the memory store's TTLs, a federation deploy check's retry wait, the profiler's recording window, deadlines and busy waits, the testing API's wait, and the perf CLI's waits. A wall-clock step no longer moves them.
