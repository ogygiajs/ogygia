# @ogygia/content

## 0.13.0

### Minor Changes

- [#177](https://github.com/ogygiajs/ogygia/pull/177) [`d9e8e2f`](https://github.com/ogygiajs/ogygia/commit/d9e8e2f2b9bad0fa5d79a60d2b2001edc11985c6) Thanks [@PuruVJ](https://github.com/PuruVJ)! - The headless on-device search handle is a class: `new SearchClient({ base })` replaces `search({ base })` (same options, same `ready`, `query()` and `destroy()`).

### Patch Changes

- [#370](https://github.com/ogygiajs/ogygia/pull/370) [`9272db9`](https://github.com/ogygiajs/ogygia/commit/9272db994d85da6bbb68e0220f7087db4ad4e4a2) Thanks [@PuruVJ](https://github.com/PuruVJ)! - The code-block copy button no longer leaves a refused clipboard as an unhandled rejection, and a second copy within the tick keeps the tick for its full time ([#365](https://github.com/ogygiajs/ogygia/issues/365)).

- [#318](https://github.com/ogygiajs/ogygia/pull/318) [`085cb73`](https://github.com/ogygiajs/ogygia/commit/085cb73a998e90e04f701090d6dacdbf5cef72f3) Thanks [@PuruVJ](https://github.com/PuruVJ)! - Content's dev reload lets go of a change it was still waiting on when its dev server closes or restarts.

- [#257](https://github.com/ogygiajs/ogygia/pull/257) [`c0b92c2`](https://github.com/ogygiajs/ogygia/commit/c0b92c20616bb27bf00b6ce20a38cd0414c4be64) Thanks [@PuruVJ](https://github.com/PuruVJ)! - An edit in dev no longer leaves another live connection open: a collection its module's next run replaces closes its connection, clears its retry and leaves the graph ([#247](https://github.com/ogygiajs/ogygia/issues/247)).

- [#257](https://github.com/ogygiajs/ogygia/pull/257) [`c0b92c2`](https://github.com/ogygiajs/ogygia/commit/c0b92c20616bb27bf00b6ce20a38cd0414c4be64) Thanks [@PuruVJ](https://github.com/PuruVJ)! - A live list or live get streaming a collection that a dev edit replaced now ends, instead of waiting forever for a change that cannot come ([#247](https://github.com/ogygiajs/ogygia/issues/247)).

- [#220](https://github.com/ogygiajs/ogygia/pull/220) [`8707255`](https://github.com/ogygiajs/ogygia/commit/8707255bfb137cbe6c0543b249a0949636070f15) Thanks [@PuruVJ](https://github.com/PuruVJ)! - A dimension coordinate whose outline failed to build once builds it again on its next page ([#192](https://github.com/ogygiajs/ogygia/issues/192)).

- [#220](https://github.com/ogygiajs/ogygia/pull/220) [`8707255`](https://github.com/ogygiajs/ogygia/commit/8707255bfb137cbe6c0543b249a0949636070f15) Thanks [@PuruVJ](https://github.com/PuruVJ)! - One bad live update no longer stops live updates: the entry keeps its last good version, and a dropped live connection is opened again (after a doubling wait) and the whole source read again ([#190](https://github.com/ogygiajs/ogygia/issues/190)).

- [#220](https://github.com/ogygiajs/ogygia/pull/220) [`8707255`](https://github.com/ogygiajs/ogygia/commit/8707255bfb137cbe6c0543b249a0949636070f15) Thanks [@PuruVJ](https://github.com/PuruVJ)! - A change made while a collection's first read runs, or between a live list's first value and its next pull, is no longer missed ([#191](https://github.com/ogygiajs/ogygia/issues/191)).

- [#371](https://github.com/ogygiajs/ogygia/pull/371) [`0c1e449`](https://github.com/ogygiajs/ogygia/commit/0c1e449b2b884b36263ce8aaa88633f89f3a1789) Thanks [@PuruVJ](https://github.com/PuruVJ)! - A dropped live connection is opened again under a named policy whose waits are spread (cut by up to a fifth), so every instance a source dropped at once no longer reconnects at the same moment.

- [#257](https://github.com/ogygiajs/ogygia/pull/257) [`c0b92c2`](https://github.com/ogygiajs/ogygia/commit/c0b92c20616bb27bf00b6ce20a38cd0414c4be64) Thanks [@PuruVJ](https://github.com/PuruVJ)! - A markdown highlighter or mdsvex start that fails once (a grammar or plugin that failed to load) no longer breaks markdown until a restart: the next render starts it again ([#248](https://github.com/ogygiajs/ogygia/issues/248)).

- [#220](https://github.com/ogygiajs/ogygia/pull/220) [`8707255`](https://github.com/ogygiajs/ogygia/commit/8707255bfb137cbe6c0543b249a0949636070f15) Thanks [@PuruVJ](https://github.com/PuruVJ)! - The site's outline (nav, pages, addresses) and its search index follow a live source's changes; a change the outline cannot be woven from keeps the last good outline and says why, and a failed search build is not kept ([#193](https://github.com/ogygiajs/ogygia/issues/193)).

- [#220](https://github.com/ogygiajs/ogygia/pull/220) [`8707255`](https://github.com/ogygiajs/ogygia/commit/8707255bfb137cbe6c0543b249a0949636070f15) Thanks [@PuruVJ](https://github.com/PuruVJ)! - Every site search query is answered or rejected: a failed query, a failed index load, a worker crash or destroy() no longer leaves one waiting ([#207](https://github.com/ogygiajs/ogygia/issues/207)).

- [#305](https://github.com/ogygiajs/ogygia/pull/305) [`e605070`](https://github.com/ogygiajs/ogygia/commit/e6050700637374f5e62d8601c0402ce98be2ffa4) Thanks [@PuruVJ](https://github.com/PuruVJ)! - The search worker downloads its index again for the next query after a failed download, instead of failing every query with the first error.

- [#318](https://github.com/ogygiajs/ogygia/pull/318) [`085cb73`](https://github.com/ogygiajs/ogygia/commit/085cb73a998e90e04f701090d6dacdbf5cef72f3) Thanks [@PuruVJ](https://github.com/PuruVJ)! - The mobile bar's sheet lets go of its pinned height after a view switch with no glide (both views the same height), and on unmount.

- [#370](https://github.com/ogygiajs/ogygia/pull/370) [`9272db9`](https://github.com/ogygiajs/ogygia/commit/9272db994d85da6bbb68e0220f7087db4ad4e4a2) Thanks [@PuruVJ](https://github.com/PuruVJ)! - A Shiki theme object with no `name` now highlights (it is named from its contents), two such themes no longer share a highlighter or a fence-cache key, a theme object edited in place is a new fence-cache key, and snippets or alternating `highlight()` configs reuse one highlighter per set of themes and languages instead of making a new one each time ([#366](https://github.com/ogygiajs/ogygia/issues/366)).
