`@ogygia/machine`: A `cache()` set of the value its key already holds keeps it (no `'delete'` notice, so an `onEvict` cleanup no longer runs on a value still held), `set` takes its own `keep`, and a keyed `flights` of one field keys by that field's value with no string built.
`@ogygia/core`: A region answer written to the frame store costs about a third fewer steps (one cache write, no lookup before it), and an island warm reads its chunk graph once.
