`@ogygia/core`: a deferred region refused with `sig`, `shape` or `foreign-key` (a server of another build or key, as in a rolling deploy from 0.12.x) asks once more after half a second, so a load balancer can route it to a server of the page's own build; if that is refused too, `region_answer_denied` says so and the fallback stands.
