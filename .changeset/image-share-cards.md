'@ogygia/image': minor

Share cards: `import.meta.og.image.card('./Card.svelte', { width, height, fonts })` returns `(props) => ImageDescriptor`, a Svelte component (and the components it imports, with their scoped CSS) drawn as a PNG by satori, satori-html and `@resvg/resvg-js` (optional peers the app installs; a build with a card and none of them fails `image_card_engine_missing`). Props are one JSON object of at most 2048 characters in the URL (`image_card_props`), signed into each file's `.card/` tail; fonts are `.woff`, `.ttf` or `.otf` files whose family, weight and style the build reads (`image_card_font`); CSS satori cannot draw fails `image_card_css`, naming the property. A prerendered page's card is drawn by the build into `_app/immutable/og/`, a live page's by the image endpoint on the first ask, kept forever and named by a digest of every module and font the card is made from; on an edge runtime a live page's card is the build's file when a prerendered page made it, else 404 with `image_no_encoder` (which gains `what: 'card'`). Descriptors gain `from: 'card'` and `card`. In dev, an `og:image` or `twitter:image` naming an AVIF or WebP file says `image_share_format`.
